# Build Zone Expander

> 项目分类：个人项目 / Besiege 游戏 Mod / 可直接使用

A Besiege 1.90 mod that enlarges the single-player campaign build zone while keeping the normal boundary system and level-completion checks enabled.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3788797275)

## Quick start

1. Download the mod from Steam Workshop, or copy the `BuildZoneExpander` folder into `Besiege_Data/Mods`.
2. Enable the mod in Besiege.
3. Restart the game and enter a single-player campaign level.
4. Use the in-game window to choose a multiplier.

Do **not** enable the vanilla Free Build / Ignore Bounds option, because that option still disables normal completion checks.

## Features

- Enlarges the visible and functional campaign build box from `1x` to `10x`.
- Defaults to `2x`.
- Includes `1.5x`, `2x`, `3x`, and `5x` presets.
- Typed values are clamped to `1x–10x`.
- Keeps the vanilla boundary and completion system enabled.
- Restores the original build box when disabled.
- Single-player only; the mod deliberately disables itself in multiplayer.

## Compatibility

Built and runtime-tested with Besiege `v1.90-25346` on Windows.

Other game versions have not been fully verified yet.

## 中文说明

这是一个用于 **Besiege 单人战役** 的建造区域扩展 Mod。

它会放大战役关卡的建造框，但不会直接开启原版“自由建造 / 忽略边界”功能，因此仍然保留正常的边界检测和关卡完成判定。

默认放大 `2` 倍，可以直接选择 `1.5 / 2 / 3 / 5` 倍，也可以输入 `1–10` 倍的数值。

### 安装

- 推荐直接使用上方 Steam Workshop。
- 手动安装时，将 `BuildZoneExpander` 文件夹放入 `Besiege_Data/Mods`。
- 在游戏 Mod 管理中启用后重启游戏。
- 进入单人战役关卡后即可使用。

请不要同时开启原版“自由建造 / 忽略边界”，否则原版逻辑仍会禁用正常通关判定。
