# Build Zone Expander

Besiege 1.90 mod that multiplies the single-player campaign build-zone transform while leaving the game's bounds and normal completion checks enabled.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3788797275)

The in-game window defaults to 2x. Presets from 1.5x to 5x are included; typed values are clamped to 1x-10x. The mod deliberately disables itself in multiplayer.

Install the `BuildZoneExpander` directory under `Besiege_Data/Mods`, enable the mod in Besiege, restart the game, and enter a campaign level. Do not enable the vanilla Free Build/Ignore Bounds option, because that option still disables completion.

## Features

- Enlarges the visible and functional campaign build box from 1x to 10x.
- Defaults to 2x, with 1.5x, 2x, 3x, and 5x presets.
- Keeps the vanilla boundary system enabled instead of toggling the Free Build cheat.
- Restores the original box when disabled.
- Single-player only; deliberately inactive in multiplayer.

## Compatibility

Built and runtime-tested with Besiege `v1.90-25346` on Windows. Other game versions are not yet verified.
